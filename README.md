# OTI Recovery app

Companion app for [Over the Influence Recovery](https://www.otirecovery.org), a San Diego non-profit supporting mothers in recovery. One codebase ships to **Google Play**, the **App Store**, and the **web** (installable PWA).

| Tab | What it does |
| --- | --- |
| Home | Next Monday group, upcoming events, day counter, mission, a story, donate |
| Calendar | Month grid with recurring events, agenda, upcoming list, event details, add-to-calendar, weekly reminder (native) |
| Phones | Verified crisis, substance-use, maternal mental health, safety, and San Diego lines with Call / Text / Copy; "My people" personal call list (on-device) |
| Tools | Private sobriety counter with milestones, box breathing, 15-minute urge timer, HALT check, recovery communities & help links |
| Community | Members-only message board: **Events** (participants + board) and **Daily Affirmations** (participants + coach). Sign-in by emailed code, moderation, reports, member admin. See `docs/COMMUNITY-SPEC.md` |
| More (top-right) | T.H.R.I.V.E. and other programs, stories of impact, newsletters, peer training (CE), get involved, social, about/privacy |

**Privacy:** no analytics, no ads. The sobriety date and contacts stay in the device's local storage; Android auto-backup is off. The optional Community stores email, display name, and posts on OTI's Supabase project, gated by Row Level Security (`supabase/schema.sql`).

## Stack

- Plain HTML/CSS/JS (ES modules, JSDoc types, `tsc --checkJs`), bundled with esbuild. No framework.
- [Capacitor 8](https://capacitorjs.com) wraps the same build for Android (SDK 36) and iOS (SPM, no CocoaPods). Plugins: `@capacitor/app` (back button), `@capacitor/local-notifications` (meeting reminders).
- Content lives in one file, `www/data/content.json`, validated by `scripts/validate-content.mjs`.
- Community backend: Supabase (Postgres + email-OTP auth + Realtime). Schema and authorization in `supabase/`, tested against a real Postgres in-process (PGlite) by `test/community-rls.test.mjs`. Setup: `docs/COMMUNITY-SETUP.md`.

## Hosting

`vercel.json` deploys `dist/site` (the review copy: sample data, dark theme locked, no sign-in) to Vercel on every push to `main`. To host the real web app instead, change `outputDirectory` to `dist`.

## Commands

```bash
npm install
npm run check        # validate content → type-check → unit tests → build dist/
npm run dev          # rebuild on change (then: npm run serve → http://localhost:4173)
npm run screenshots  # phone screenshots for the stores (needs Chromium; see script header)

npm run sync         # build + copy web assets into android/ and ios/
npm run android:open # Android Studio
npm run android:bundle  # signed .aab (needs android/keystore.properties; see STORE-LAUNCH.md)
npm run ios:open     # Xcode (macOS)
npm run assets       # regenerate native icons/splash from resources/
```

## Editing content

Edit `www/data/content.json`, bump `version` (YYYY-MM-DD), run `npm run validate:content`.

- **Events** use wall-clock Pacific times (`"start": "2026-10-05T19:00"`, `"timezone": "America/Los_Angeles"`). Weekly recurrence: `{ "freq": "weekly", "byDay": ["MO"], "until": "2026-12-31", "exdates": ["2026-11-30"] }`. Times convert correctly across daylight saving and for users in other time zones.
- **Phones** need `number` as digits only (`"18006624357"`) plus a human `display`. Set `number: null` for text-only lines and add `sms: { "number": "741741", "body": "HOME" }`.
- **Testimonials** must be real and consented; the app renders exactly what is in the file.
- With `remoteContentUrl` set in `www/js/config.js`, published changes reach installed apps on next launch without a store release.

## Project layout

```
www/                 source web app (index.html, styles.css, js/, data/content.json, assets/, fonts/, privacy.html)
dist/                build output (git-ignored) — Capacitor's webDir; standalone.html = single-file preview, review.html = same with the Community on sample data (no login)
supabase/            schema.sql (tables, triggers, RLS), seed.sql (topics + visibility matrix), first-members.sql
docs/                COMMUNITY-SPEC.md (roles, matrix, API, rules), COMMUNITY-SETUP.md (switch-on steps)
android/, ios/       native projects (generated by Capacitor, committed)
resources/           icon/splash sources for @capacitor/assets
store/               listing copy, icon, feature graphic, screenshots
scripts/             build, serve, validate-content, screenshots, gen-keystore
test/                node --test unit tests (calendar engine, phone helpers)
.github/workflows/   check, android-release (AAB → Play), ios-testflight, pages (web hosting)
STORE-LAUNCH.md      step-by-step store submission guide
```

## Tests

`npm test` covers the calendar engine (recurrence, DST, ranges, multi-day, upcoming ordering, Google Calendar links, day counting), the phone helpers (formatting, validation, tel:/sms: links, search, grouping), the Community authorization layer (24 tests against the real schema in an in-process Postgres), and the Community UI helpers and demo adapter.
